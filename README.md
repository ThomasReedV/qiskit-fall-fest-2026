# qiskit-fall-fest-2026
Soluciones de los challenges de Qiskit Fall Fest 2026: Circuit Cutting e Ising Model con SQD

Aprendizajes personales

Algo que noté mientras desarrollaba estos challenges es que una parte importante del trabajo requiere conocimientos de Python. Además de comprender los conceptos de computación cuántica, tuve que trabajar con funciones, bibliotecas, estructuras de datos y diferentes formas de analizar los resultados.

Considero que los ejercicios me ayudaron a entender mejor cómo se relacionan la programación y la computación cuántica. También me hicieron ver que necesito seguir fortaleciendo mis conocimientos de Python para poder desarrollar este tipo de proyectos con mayor facilidad.
