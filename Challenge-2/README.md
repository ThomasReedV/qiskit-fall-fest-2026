Challenge 2 - Ising Model y SQD
Solución del segundo challenge de Qiskit Fall Fest 2026.
En este trabajo se estudia el modelo de Ising transversal, la evolución temporal de un sistema cuántico y la aproximación de Trotter.
También se analizan las correlaciones entre espines, los errores de simulación y el uso de SQD con diferentes estados iniciales.
El código está documentado en español e incluye gráficos, resultados y conclusiones.
